# Art Style Guide - Echoes of Resonance

**Final Decision**: Cute Chibi 2D

### Overall Style
- **Style**: Chibi / Super-deformed cute monster style
- **Inspiration**: Pokémon + Digimon + Studio Ghibli + modern mobile monster collectors
- **Key Characteristics**:
  - Big expressive eyes (main emotional focus)
  - Soft glowing effects and particle accents
  - Rounded, huggable silhouettes
  - Vibrant but soft color palette
  - Clean outlines with light shading
  - Consistent chibi proportions across all monsters

### Technical Approach
- **Format**: 2D Sprites (PNG)
- **Animation Method**: Rigged 2D (Unity 2D Animation / Spine) for idles, emotions, and simple actions
- **Evolution Style**: Smooth morph transitions + particle effects
- **Resolution Target**: 
  - Monsters: 512x512 or 1024x1024 base (downscaled as needed)
  - UI/Icons: 256x256
- **Backgrounds**: 2D illustrated environments (floating sky islands, rifts, ranch)

### Color Palette
- Bright, saturated but soft tones
- Strong use of glows and emissive effects for Resonance theme
- Each monster lineage has its own dominant color family while staying cohesive

### Current Assets
- Base forms generated with Grok Imagine (Fluffling, Droplet, Sproutling, Spark)
- Future assets: Evolutions, expressions, effects, ranch backgrounds

### Guidelines for New Monsters / Assets
- Always maintain big eyes and chibi proportions
- Keep visual consistency across evolutions (same color family + silhouette DNA)
- Every monster must feel cute even in final evolutions
